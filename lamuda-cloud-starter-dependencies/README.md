# lamuda-cloud-dependencies

## 简介
  dependencies 模块提供了所有的脚手架组件依赖集合，当时用到大多数组建的时候，用户避免一个一个的组件引入。
 
## 项目依赖
  没有当前脚手架依赖

## 使用方式
  项目的pom文件中添加以下依赖：
```
        <dependency>
            <groupId>${project.groupId}</groupId>
            <artifactId>lamuda-cloud-starter-dependencies</artifactId>
            <version>${project.version}</version>
        </dependency>
```

  无
